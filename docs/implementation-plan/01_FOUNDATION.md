# Phase 1: Reproducible Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:test-driven-development. Execute only this file. Read `00_MASTER.md` first.

**Goal:** Make the current proof of concept installable, testable, deterministic, and capable of writing validated research artifacts.

**Architecture:** Keep the application modules intact. Add a small `ait.artifacts` boundary for provenance and atomic JSON writes, plus repeatable project commands. Research code in later phases must write through this boundary.

**Tech Stack:** Python 3.12, Pydantic 2, pytest, AnyIO, Ruff, uv, GNU Make.

## Global Constraints

All constraints in `00_MASTER.md` apply. This phase must not add scenarios, live API calls, benchmarks, or paper results.

## Public Interfaces

Implement these exact interfaces:

```python
# ait/artifacts.py
from pathlib import Path
from typing import Any

class Provenance(BaseModel):
    schema_version: Literal["1.0.0"] = "1.0.0"
    generated_at_utc: datetime
    command: list[str]
    seed: int = 20260727
    git_commit: str | None
    python_version: str
    platform: str

class ArtifactEnvelope(BaseModel):
    provenance: Provenance
    experiment: str
    configuration: dict[str, Any]
    payload: dict[str, Any] | list[Any]

def collect_provenance(command: list[str], seed: int = 20260727) -> Provenance: ...
def redact_secrets(value: Any) -> Any: ...
def canonical_json_bytes(envelope: ArtifactEnvelope) -> bytes: ...
def write_artifact(path: Path, envelope: ArtifactEnvelope) -> Path: ...
def read_artifact(path: Path) -> ArtifactEnvelope: ...
```

`redact_secrets` must recursively replace values for case-insensitive keys named `authorization`, `access_token`, `refresh_token`, `token`, `client_secret`, `secret`, `api_key`, `apikey`, `cookie`, or keys ending in `_token` or `_secret` with `"[REDACTED]"`. Explicitly exempt aggregate metadata keys ending in `_count`, so `token_count` remains unchanged.

`write_artifact` must create parent directories, redact before validation/serialization, write to a temporary sibling, call `os.replace`, and end the file with one newline. JSON keys must be sorted.
